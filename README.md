# Portfolio - Zainulabidin

A modern, responsive portfolio website built with Next.js 16, React 19, TypeScript, and Tailwind CSS.

## Features

- ✨ Modern UI with smooth animations (GSAP, AOS, Lenis)
- 🎨 Responsive design with mobile-first approach
- ⚡ Built with Next.js 16.2.12 (Turbopack for fast development)
- 🎭 Interactive components with React 19
- 💅 Styled with Tailwind CSS 4
- 🌊 Smooth scrolling with Lenis
- 🎬 Advanced animations with GSAP
- 📱 Fully responsive across all devices

## Tech Stack

- **Framework**: Next.js 16.2.12
- **React**: 19.2.4
- **TypeScript**: 6.0.3
- **Styling**: Tailwind CSS 4
- **Animations**: GSAP 3.15.0, AOS 2.3.4, Lenis 1.3.25
- **Icons**: Lucide React 1.28.0

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Build for Production

```bash
npm run build
npm start
```
